## Download and inspect

With GitHub CLI installed:

```powershell
gh release download snapshot-2026-11-06 --repo NithisNandhan/sentinel-vehicle-intelligence-prototype --dir data/snapshot-download
python tools/handoff_archives.py restore --manifest data/snapshot-download/research-reports-public-20261106.manifest.json --destination data/restored-research
python -m http.server 7777 --bind 127.0.0.1 --directory data/restored-research/benchmarks/reports/ocr-input-review-20261106
```

Then open `/automatic-crops.html`, `/text-boundaries.html` or `/refinement.html`.
Each archive must be restored separately into an empty destination; the restore
tool validates part sizes and SHA256 digests. Other bundles use the same command
with their own manifest and fresh destination. Do not overwrite an active model
volume or populated database. Use the existing handoff event-restore tools for
the fresh `saved-events` snapshot only after preparing an empty destination.

## Inputs deliberately not published in this public supplement

The repository is public. Not every locally downloaded input grants unrestricted
redistribution:

- `data/benchmarks/fresh-indian-20261101/academic/permission.json` explicitly marks
  its source as private noncommercial evaluation, without redistribution of its
  images/crops. Its source is
  <https://www.kaggle.com/datasets/saisirishan/indian-vehicle-dataset>.
- The Datacluster evaluation sample has its own CC-BY-NC-ND/evaluation-only notice.
  Preserve and read its publisher terms before obtaining it independently.
- The Mumbai clip comes from
  <https://www.pexels.com/video/busy-urban-traffic-scene-in-mumbai-city-30400506/>.
  The current [Pexels terms](https://www.pexels.com/terms-of-service/), section 5,
  restrict standalone distribution. The raw clip and raw standalone crops are
  therefore not mirrored here. Source receipts and frame/crop annotations remain
  available; the saved review pages combine crop evidence with analysis.
- Root `sample.mp4` has no verified public redistribution receipt.
- Unverified `dats_probe` material is not promoted into a public dataset backup.
- Credentials, authenticated camera URLs and assistant state are excluded.

These exact input files remain local. The public supplement is not a complete
offline replacement for them. Do not treat this as confirmation that the laptop
can be erased and every private/restricted input restored from the public repo.
The earlier release remains unchanged; it is a historical snapshot.
